## [0.1.0] - 2026-07-24

### Added
- GitHub repository analysis engine (framework, language, package manager,
  testing, CI, deployment, database detection).
- Modular AI provider architecture with a free local generator and an
  OpenRouter-backed live provider.
- Generation of 15 document types: README, API docs, architecture overview,
  folder structure, installation guide, setup guide, environment variables,
  database docs, feature docs, component docs, onboarding guide, deployment
  guide, FAQ, contributing guide, changelog template.
- Streaming document generation with per-document status tracking.
- Markdown editor with live preview and export to Markdown/HTML/DOCX.
- Local project history via `localStorage`.
- Landing page, dashboard, Vitest test suite, and CI workflow.
